# OrderedListsSigma16

 This program executes commands on an array of ordered linked lists.
 The supported operations are terminate, insert, delete, swap, and print.
 The program reads commands from a statically defined input array and
 performs the required linked-list operations using assembly language.

 General description of the program

 The program performs a sequence of operations on linked lists;
 the operations include insertion, deletion, and swap.  The input
 is an array of records, where each record contains a code
 indicating which operation to perform, and arguments for the
 operation.  The input array is defined statically using data
 statements.
